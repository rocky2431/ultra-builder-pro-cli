# Stage D preregistered bounded operational comparisons

The original C failures and completed 35-minute expense-ledger pair remain intact. This experiment compares current operational helpers with the same finite Step 1 method and fair Solo. It is not a held-out evolution experiment and does not promote a strategy.

Before any new model run, freeze two shapes and two repetitions: expense-ledger / pi-foundation-v1, each with operational Factory, manual-packet Step 1 Factory and Solo; tree-manifest / pi-balanced-v1, each with operational Factory and Solo. Ten runs total, 35 minutes each, Sol Primary, the profile's fixed challenger/workers/Astra independent assessor, same acceptance and initial Git commit inside each matched set. A task set can run concurrently; provider contention is a measurement limitation. No model receives another treatment's outcomes. No runtime steering or mid-run fixture/prompt changes. Failed runs stay in the denominator; do not add successful reruns to replace them. Profile is confounded with shape; no causal profile ranking is supported.

Both implementations must consume a real independent current-revision task Review and complete the same canonical Task Evidence, Test and Deliver archive. The Factory has an actual Challenger, overlapping disjoint worker wave and final Review. Max two repair iterations and existing bounded Review apply. A separate coupled-work route observation must choose Solo without spawning implementation workers. Native W3 was qualified separately; these matched foreground experiments select W1 uniformly.

Primary outcomes: immutable goal/acceptance and independent quality, canonical closure, complete elapsed time, native role calls/tokens/cost, repair and human intervention count, useful actual worker overlap, lifecycle failures and preserved data. For the expense shape, compare both operational repetitions against their paired Step 1 method; against Solo report all costs whether improved or worse. Benefit requires a repeated observed improvement with no quality/authority regression; success alone is not benefit. Record tradeoffs rather than changing an acceptance criterion. Tree-manifest adds repeated second-shape/profile coverage; two repetitions are characterization, not a population estimate.

Native runtime and Ultra source hashes plus exact prompts/fixtures/results/raw sessions are retained. Only sample source and local commits are delegated; Codex remains the sole author of Ultra implementation/tests. No HOME installation, source publication or external effects beyond existing authorized model calls.
