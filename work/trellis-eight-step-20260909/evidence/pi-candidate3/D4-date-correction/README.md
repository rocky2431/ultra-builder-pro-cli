# mnotes — 会议记录归档 + 关键词检索

只干一件事：**过后按关键词把「上次那个决定」找出来，并且看得到是哪天记的。**

单人、单机、纯 Python 标准库，没有任何依赖，不联网，不共享。

## 用起来

```bash
chmod +x mnotes.py        # 只需一次
```

### 1. 把已有的散记导进来（原文件只读，一个字都不改）

路径由你给，工具不内置任何默认扫描目录：

```bash
./mnotes.py import ~/Documents/会议
./mnotes.py import ~/Desktop/周会.md      # 单个文件也行
```

- 递归找 `.md` `.markdown` `.txt` `.text`
- 日期优先取文件名里的 `2026-09-08` 或 `20260908`，取不到就用文件修改时间
- 重复导入不会重复入库；原文件改过之后再导，会**新增一条**，旧措辞仍然搜得到

### 2. 开会时随手记

```bash
./mnotes.py add -m "决定：Q4 预算砍一半，先保上线"
./mnotes.py add -d 2026-09-08 -t "产品周会"      # 补录，正文从标准输入读
```

省略 `-d` 就是今天；省略 `-t` 就取正文第一行当标题。

### 3. 找回来（核心）

```bash
./mnotes.py find 预算
./mnotes.py find 决定 供应商     # 多个关键词 = 都要命中
```

输出长这样，日期就在编号旁边：

```
#4  2026-09-08  临时对齐
    决定：预算的事下周一给最终版

#1  2026-08-12  产品周会
    决定：把 Q4 预算砍掉一半，先保上线
    来源：/Users/you/Documents/会议/2026-08-12-产品周会.md
```

只打印命中的那几行。要全文：

```bash
./mnotes.py show 1
./mnotes.py list -n 30           # 按日期倒序看最近的
./mnotes.py edit-date 1 2026-09-10  # 选中 #1，修正记录日期
```

`edit-date` 只更新库里的日期，不会改动导入的原文件；修改后 `find`、`show` 和 `list` 会立即使用新日期。

找不到时会明说，并返回退出码 1（方便你写脚本）。

## 笔记库放在哪

默认 `./data/notes.db`（一个 SQLite 文件）。想换地方：

```bash
export MNOTES_DB=~/Dropbox/notes.db
# 或每次： ./mnotes.py --db /path/to/notes.db find 预算
```

备份就是复制这一个文件。

## 两个说明白的取舍

**检索用子串扫描，不是全文索引。** 因为实测 SQLite FTS5 的 trigram 分词对「预算」
「决定」这类两字中文词**返回 0 条命中**——正是你最可能搜的词。子串匹配中英文都准，
单人几万条笔记的规模下毫秒级。真到明显变慢时，升级路径是接 CJK 分词器（jieba/ICU）
的 FTS5 索引，代价是引入依赖。

**只做归档和检索，不自动提炼待办/责任人/截止日。** 你给的成功判据只要求找回决定本身，
这项没被要求，也没被排除——需要的话再加。
