## Disposable money operation

The first attempt had an operator error: the Node command used `require(process.env.MONEY_JS)` without exporting `MONEY_JS`, so Node returned `TypeError [ERR_INVALID_ARG_TYPE]` before loading the product. No source or fixture was changed. It was corrected by setting `MONEY_JS="$QA/money-split/src/money.js"` for the same operation.

Corrected command:

```sh
MONEY_JS="$QA/money-split/src/money.js" node - <<'JS'
const {splitAmount, formatAmount, summarizeSplit} = require(process.env.MONEY_JS);
try { splitAmount(1000, 0); } catch (e) {
  console.log('zero_error', e.name, e.message);
  if (!(e instanceof RangeError) || !e.message.includes('大于 0')) process.exit(1);
}
const shares = splitAmount(1000, 3);
console.log('shares', shares, 'sum', shares.reduce((a,b)=>a+b,0),
  'formatted', shares.map(formatAmount), 'summary', summarizeSplit(1000,3));
if (JSON.stringify(shares)!=='[334,333,333]' || shares.reduce((a,b)=>a+b,0)!==1000) process.exit(1);
JS
```

Observed:

```text
zero_error RangeError 人数必须是大于 0 的整数（当前输入：0）
shares [ 334, 333, 333 ] sum 1000 formatted [ '3.34', '3.33', '3.33' ] summary 合计 10.00，3 人平摊：1 人 3.34，2 人 3.33
```

Status: **PASS** — zero has a clear Chinese RangeError; 1000 minor units are conserved and split as 334+333+333.
