## 解释边界

脚本 Owner 输入 + 真实 provider 执行，不是真人可用性证据；只有一个 Host/模型和小样本，不支持生产率泛化。五次调用费用字段合计 3.498735 美元，是原生服务按标价报告的口径，不是账单实付；累计调用墙钟 750.50 秒包含并行重叠，不能当整体耗时。Owner 主动投入未测量，不记成零。

全局 Hindsight 等插件照常加载：F1 续轮自动记忆曾把序列化器误写成解析器，模型查源码后纠正；部分 memory MCP 读写被原生权限拒绝。F3 fresh 回合记录到的自动召回只有“无相关资料”，没有前一任务事实。这些是实际环境证据，不变成 Ultra 的功劳或缺陷。未来相同 case 名会共用宿主 memory bank，候选试跑需用新且唯一的项目目录名并记录召回，不能把基线经验暗带进预留或候选会话。

F3 的 README seed 遗留旧 `node --test test/` 文案，模型又将其用于 npm test；它在本次 Node26 环境可运行，但不能据此声称 Node25 兼容，更不能把评测材料诱发的写法归为 Ultra 原生缺陷。尚无预留案例进入模型。
