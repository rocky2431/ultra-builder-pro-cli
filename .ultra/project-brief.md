> **Authority**: raw owner intake preserved from the project's pre-split North Star. It

## One-line

一次性把 Ultra Builder Pro v0.26 的 Skill、Hook、五端安装、跨 CLI delegation 和
`.ultra/` 文档生命周期全部完善到可验证、可恢复、无孤儿文档的状态。

## Initial Outline

- What it is: a file-first workflow plugin shared by five coding CLI hosts.
- Broadly for whom or what: an owner and host model carrying software work across
  sessions, repositories, and supported CLIs.
- Intended result: portable Skills, bounded Hooks, delegated execution, and a complete
  owner-readable artifact lifecycle that work through real installed surfaces.
- Broad boundary: Ultra owns its workflow artifacts and adapters, not general memory,
  code graphs, deployment providers, or an MCP/SQLite semantic runtime.

## Explicit Inputs

- Claude Code, Codex, OpenCode, Kimi Code, and Grok Build receive the same product.
- Owner-invoked workflows stay explicit; model-invoked disciplines stay internal.
- Commit, push, publication, installation, and provider calls remain separate effects.
