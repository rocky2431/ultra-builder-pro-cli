# Project North Star

> **Authority**: the owner's literal intent for this repository. Every active Change,
> task, artifact, and verification claim must trace back here.

## One-line

一次性把 Ultra Builder Pro v0.26 的 Skill、Hook、五端安装、跨 CLI delegation 和
`.ultra/` 文档生命周期全部完善到可验证、可恢复、无孤儿文档的状态。

## Hard Constraints

- Claude Code, Codex, OpenCode, Kimi Code, and Grok Build must receive the same
  fourteen-Skill product through host-native plugin or bundle surfaces.
- Owner-invoked workflows remain explicit; model-invoked disciplines are selected by
  the model only inside an already authorized task.
- Project truth remains owner-readable files plus Git. Do not restore an Ultra
  database, MCP kernel, semantic state machine, prompt projection, or daemon.
- Every canonical artifact has a named writer, consumer, freshness rule, and recovery
  route. Generated observations never become semantic authority.
- Delegation grants no new authority. Instructions, permissions, worktree changes,
  receipts, timeout, cancellation, and recovery remain mechanically inspectable.
- Commit, push, publication, real HOME installation, and authenticated provider calls
  remain separately authorized external effects.

## Notes for agents

1. Re-anchor on the One-line before interpreting an active Change.
2. Check Hard Constraints before adding a mechanism or widening an effect boundary.
3. Treat a green unit suite as evidence, not as proof of five-host installation or an
   end-to-end user outcome.
