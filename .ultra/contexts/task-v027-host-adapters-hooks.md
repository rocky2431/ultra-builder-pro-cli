# Task v027-host-adapters-hooks: Close native adapter and Hook behavior on all six hosts

## Context

**What**: Complete native installation, Hook/event wiring, permission profiles, and
delegation semantics for Claude Code, Codex, OpenCode, Kimi Code, Grok Build, and ZCode.

**Why**: Shared Skills are portable only when each adapter absorbs real Host differences
and reports unavailable capabilities instead of silently dropping observations.

**Constraints**:
- Keep Skills host-neutral; adapt semantics in adapter/plugin/wire layers.
- Do not emulate native gaps through a new supervisor or lowest common denominator.
- `.ultra/progress` remains optional; no-active-task edits receive advisory only.
- Separate ZCode plugin integrity from headless provider readiness.

## Implementation

**Layers touched**: package assets, native Host plugin/registry, Hook events, headless CLI,
permission/readiness, Doctor input, and documentation.

**Pattern**: one semantic contract with six evidence-backed native projections.
