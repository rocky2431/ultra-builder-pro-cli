# Retained raw archives

These exact raw archives were observed at the work/ paths listed in INDEX.json. They are retained with the archived Change so binary experiment history is not counted as changed product source by worktree_digest. Original indexes and observations keep their exact reviewed bytes. Local observed paths remain present.

On a fresh checkout, copy each retained_path to its observed_path after checking its SHA-256, then extract the selected archive into an isolated directory. This restores historical evidence only and never authorizes execution. No live model, credential, or writer restart is needed.
